# 🏦 Sistema Bancário com Python

## Descrição do Projeto

Este projeto tem como objetivo desenvolver um sistema bancário simples utilizando a linguagem Python, colocando em prática os conhecimentos adquiridos durante a Formação Python da DIO.

A aplicação apresenta um menu interativo que permite ao usuário escolher entre diferentes operações bancárias, como criação de conta, acesso à conta, depósito, saque e consulta de extrato.

O desenvolvimento busca simular o funcionamento básico de um sistema bancário, aplicando conceitos fundamentais de lógica de programação e organização de código.

## Funcionalidades

- Criar conta bancária.
- Acessar conta.
- Realizar depósitos.
- Realizar saques.
- Consultar extrato bancário.
- Encerrar o sistema.

## Conceitos de Python utilizados

- Variáveis e tipos de dados.
- Estruturas condicionais (`if`, `elif` e `else`).
- Laços de repetição (`while`).
- Entrada de dados com `input()`.
- Exibição de informações com `print()`.
- Controle de fluxo com `break`.

## Objetivo de Aprendizagem

O principal objetivo é aprimorar minhas habilidades em Python, desenvolver o raciocínio lógico e compreender como construir uma aplicação com funcionalidades organizadas e interativas.

Este projeto faz parte da minha jornada de aprendizado em programação e representa mais um passo na construção do meu portfólio de desenvolvimento.

**Tecnologia utilizada:** Python 3.

**Plataforma de aprendizagem:** DIO – Digital Innovation One.
Praticar a construção de uma aplicação em Python, organizar o código em classes, aplicar regras de negócio e utilizar Git e GitHub para documentar e compartilhar a evolução do projeto.
